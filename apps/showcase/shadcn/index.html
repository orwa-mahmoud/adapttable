@adapttable/shadcn

AdaptTable for shadcn

A shadcn/ui data table, styled by the classes you already own.

A framework-neutral @adapttable/core provides the data engine; @adapttable/react connects it to React. Add features through explicit imports. The visible controls are semantic markup wearing shadcn's own class conventions.

That is the whole trade: one model to learn, and a table that belongs in a shadcn app rather than sitting inside one.

Install

pnpm add @adapttable/shadcn @adapttable/core

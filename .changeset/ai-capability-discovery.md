Optional `@adapttable/ai` publishes a versioned capability manifest and a
catalog/describe/execute session. `tableAgent` is an opt-in React feature.
The live table runtime now exposes `featureIds()` and optional `query`
setters so a feature above the chrome can apply ordinary view operations.
Core, adapter and server roots do not import the new package.

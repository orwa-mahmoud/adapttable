A budgeted context always lists every column. Only the author's description and
examples are deferred when a table does not fit, and the note names which — so a
compact contract can no longer read to a model as a table with fewer columns
than it has.

`rows.delete` addresses rows the way `edit.cells` does: a stable `rowKey` or a
1-based `position`, resolved before anything is removed, so a reference that
names no row is refused while the deletion is still a proposal. A proposal that
names no column is drawn as the row it deletes rather than as a cell change.
`view.setFilters` answers with the filter bag it applied. `rows.read` states
that `offset` counts from the start of its scope.

"Always allow" is drawn. The control appears on an approval the table opted in
— never a destructive one, never a write that enumerates rows — and
`bridge.alwaysAllowed` publishes what a reader waved through to a panel mounted
outside the table, which `useTableAssistant` takes as `alwaysAllow` so the
standing decision can be taken back. The label is `alwaysAllowProposal`,
translated in every locale.

Opening the assistant moves focus to the composer, as closing it already
returned focus to the launcher.

AdaptTable — live demo, every UI kit

One dataset, one API, eight renderings. This demo flips the same table between Mantine, MUI, Chakra UI, Ant Design, Radix, Base UI, Tailwind/shadcn and an unstyled build without changing a line of table code — every kit mounts its own native components, never a themed imitation of another.

What you can drive here

  • Declarative filters in a popover or drawer, with active-filter chips and numeric, date and status editors.
  • Multi-column sorting, pagination, and row selection with bulk actions.
  • Column management — show and hide, reorder, pin left or right, resize, and switch density.
  • State synced to the URL, so any view can be copied and shared.
  • Dark mode, and a responsive card layout on narrow screens.

# @adapttable/element-plus

Element Plus controls for the AdaptTable Vue binding.

AdaptTable owns query, selection, editing and table state. The adapter uses
Element Plus components for the controls. The table's semantic
structure comes from AdaptTable's Vue Chrome.

Element Plus is a peer dependency. Its official installation and theme setup are
at [element-plus.org](https://element-plus.org/en-US/guide/installation.html).

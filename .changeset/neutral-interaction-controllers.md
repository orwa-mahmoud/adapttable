Core exports the table's interaction controllers: cell editing (drafts, validation, save state, undo and redo), grid focus and cell navigation (ranges, fill, clipboard, paste and announcements against a container element), the row reorder engine (keyboard grab, drag and drop, grouped and tree moves), and the models behind find in table, the context menu, the command palette, the export handler, saved views, the header-filter overlay and the status announcements. React's hooks subscribe to them with their API and behaviour unchanged.

@adapttable/chakra

AdaptTable for Chakra

A Chakra data table, with Chakra's controls throughout.

A framework-neutral @adapttable/core provides the data engine; @adapttable/react connects it to React. Add features through explicit imports. The visible controls are Chakra's Table, Popover, Drawer, Card, Checkbox and NativeSelect.

That is the whole trade: one model to learn, and a table that belongs in a Chakra app rather than sitting inside one.

Install

pnpm add @adapttable/chakra @adapttable/core @chakra-ui/react @emotion/react

`collectConformanceTests` (`@adapttable/core/conformance`) runs a shared suite written with `describe`, `it`, `beforeEach` and `afterEach` in any test runner: it returns a flat list of named tests, each carrying its group's hooks, supports `it.each` and `describe.each`, and names an object case's tests by its keys (`$key`).

Every Vue kit publishes the same entry points. Element Plus, Naive UI, Nuxt UI and Vuetify add `/export-csv`, `/export-pdf` and `/export-xlsx`, whose `exportPdf` and `exportXlsx` draw the export control with the kit's own button; Quasar adds `/export-csv`. Naive UI and Quasar add `/columns` and `/rows`.

The assistant panel reads as a conversation. The reply leads at the size of an
answer and the action cards sit under it as quiet evidence rather than a stack
of bordered panels. A turn in flight says so where the reply will land, with
dots that hold still under `prefers-reduced-motion`.

Shortcuts open from an icon in the composer, from the first frame, and the
menu scrolls inside a capped height instead of running off the panel. Each kit
draws it with its own menu.

Three things that were written for a caller no longer reach the reader: a read
that was refused and then recovered from draws no card, a turn that stopped
short says what that means for them rather than naming continuations, and a
pinned row says "Row pinned" instead of "Column pinned".

Capabilities publish the values they accept as JSON Schema enums built from the
live table — filter keys, their operators and options, and the column ids each
view capability will take — so a caller can no longer spell a choice that was
never on offer.

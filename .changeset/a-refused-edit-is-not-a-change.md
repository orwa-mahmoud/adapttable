A refused or staged edit is spoken as a proposal, not a change. The receipt
shows the same before-and-after either way, but a reader using a screen reader
heard "Changed from 170 to 185" for an edit the table had just refused.
`assistantReceiptProposed` is the sentence for an edit that has not been
applied, in all seventeen locales.
